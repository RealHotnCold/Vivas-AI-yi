# UI Specification

## Farmer mode

### Screen 1 — Home
Show:
- location
- crop
- overall risk
- large voice button
- primary action

### Screen 2 — Climate Risk
Show:
- rainfall anomaly
- temperature anomaly
- water stress
- crop stress
- risk level
- data freshness/source

### Screen 3 — What Should I Do?
Show recommendation cards:
- action
- reason
- expected impact
- resource requirement
- confidence/limitations where applicable

### Screen 4 — Stress Test
Show:
- selected climate scenario
- baseline result
- adapted result
- loss avoided
- resource cost
- resilience change

## Expert mode

Screens/components:
- regional map
- climate layers
- crop condition
- scenario controls
- constraints
- intervention selector
- optimization result
- comparison chart
- data provenance panel

## Stitch guidance

Do not invent scientific numbers.

Use placeholders in designs where backend data is not yet available.

Design components so real API responses can replace placeholders without redesigning the interface.

## Accessibility

- Tamil + English
- large touch targets
- simple labels
- icon + text rather than color alone
- voice-first option
